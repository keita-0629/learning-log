# 11/11 学習記録

## 学習内容
- `UsageRequestService` の日別利用人数集計をDB対応
- `UsageRequestMapper` に日付ごとの利用人数を取得するSQLを追加
- `COUNT(*)` と `GROUP BY` を使用して日別人数を集計
- DBから取得した `List<Map<String, Object>>` を `Map<LocalDate, Integer>` に変換
- 職員画面のカレンダーでDBに保存された利用人数が表示されることを確認
- 職員画面で11月3日の田中太郎の利用希望が表示されることを確認

## 学んだこと
- `GROUP BY` は同じ値を持つデータをグループ化するSQL
- `COUNT(*)` はデータの件数を数える
- 拡張for文を使うと、List内のデータを1件ずつ取り出せる
- `Map` の `get()` で指定したキーに対応する値を取得できる
- キャストを使うことで、取得した値を必要な型として扱える
- DBから取得したデータをJava側で加工して画面に渡す流れを学んだ

## 苦戦
- SQLの集計結果をJavaのMapに変換する処理が難しかった
- `Object`、キャスト、`instanceof` を組み合わせた型変換を理解するのに苦戦
- `getDailyCounts()` のMapper側メソッド未定義エラーが発生
- DB移行に伴い、従来のListを使用した処理とDBを使用した処理の違いに混乱
