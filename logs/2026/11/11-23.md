# 11/23 学習記録

### ① 学習内容
- 本日はpaizaのCランク対策を中心に学習。
- `for`文を使った繰り返し処理と、`if`文による条件判定を復習。
- 入力された複数の数値から、条件を満たすものの件数を数える問題に取り組んだ。
- `%`（剰余演算子）を利用し、繰り返し割り当てられる仕事の担当者を求める問題に挑戦。
- `String`型と`int`型の違い、先頭の0を保持する方法を確認。
- `&&`（論理AND）を使った数値の範囲判定を学習。

### ② 学んだこと
- `for`文の中で入力を取得すると、繰り返しごとに異なる値を処理できる。
- 条件を満たした回数を数える場合は、`count`を0で初期化し、条件成立時に`count++`で加算する。
- 件数を数えるだけなら、必ずしも`List`などにデータを保存する必要はない。
- `%`は割り算の余りを求める演算子で、順番が繰り返される処理にも利用できる。
- `int`型では先頭の0が保持されないため、文字列として扱う必要がある。
- Javaでは`2 <= N <= 9`のような連続比較はできず、`2 <= N && N <= 9`のように条件を分ける。

- `%`を使った担当者の計算と、余りが0になる場合の処理。
- 繰り返し処理の中で変数が更新されても、目的の値だけを出力できる仕組みの理解。
- 条件式の構文や比較演算子の使い方。
