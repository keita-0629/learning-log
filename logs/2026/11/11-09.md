# 11/9 学習記録

## 学習内容
- `UsageRequest` のDB移行に着手
- `UsageRequestService` の `ArrayList` による利用希望管理を確認
- 利用希望をDBに保存するためのテーブル構造を設計
- H2に利用希望管理用のテーブルを作成
- `UsageRequestMapper` を作成し、`@Insert` と `@Select` を実装
- `UsageRequestService` の登録・取得処理をMapper経由のDB管理へ変更
- H2コンソールで利用希望データの登録・取得を確認

## 学んだこと
- Javaの `ArrayList` とDBによるデータ管理の違い
- SQLの `CREATE TABLE` を使用したテーブル作成方法
- `@Insert` でJavaのデータをDBに保存する仕組み
- `@Select` でDBからデータを取得する仕組み
- Controller → Service → Mapper → DB のデータの流れ
- DBから取得したデータをJavaのオブジェクトに対応付ける方法
