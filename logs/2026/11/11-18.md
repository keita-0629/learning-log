# 11/18 学習記録

### ① 学習内容
- MySQL WorkbenchでSQLを実行し、長期休暇期間を保存する`vacationperiods`テーブルを作成。
- `VacationMapper`を新規作成し、INSERT・SELECTを実装。
- `VacationPeriod`にID、Setter、引数なしコンストラクタを追加。
- `VacationPeriodService`を修正し、List管理からMySQLを利用する処理へ変更。
- `StaffController`の長期休暇登録処理を修正。
- paizaでJavaの問題演習。

### ② 学んだこと
- MySQL WorkbenchではSQLを実行してテーブルの作成やデータ操作ができる。
- `AUTO_INCREMENT`を使うと、IDを自動採番できるためINSERT時に指定する必要がない。
- MyBatisの`@Param`は、Javaの引数とSQL内のパラメータを対応付ける役割を持つ。
- `SELECT *`でテーブルの全カラムを取得できる。
- DBから取得したデータをEntityに格納する際、引数なしコンストラクタやSetterが利用される。
- ServiceからMapperを呼び出すことで、DBへの登録・取得ができる。

### ③ 苦戦したこと
- INSERT文で自動採番されるIDを指定する必要があるか迷った。
- `@Param`と`@RequestParam`の違いや役割を復習した。
- DB移行に伴い、Serviceのコンストラクタや既存のList管理を修正する必要があった。
- テストコードが旧コンストラクタを使用しており、ビルドエラーが発生した。
