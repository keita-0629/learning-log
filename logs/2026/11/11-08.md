# 11/8 学習記録

## 学習内容
- `Contract` のDB移行を進め、契約情報の登録・取得・更新処理を実装
- `ContractMapper` に `@Insert`、`@Select`、`@Update`、`@Delete` を実装
- `@Results` を使用し、DBから取得した契約情報を `Contract` と `Child` に対応付け
- `ContractService` の不要な `ArrayList` によるメモリ管理を削除
- 職員画面に契約曜日の削除ボタンを追加
- Controller → Service → Mapper → DB の削除処理を実装
- H2コンソールで契約情報の更新・削除を確認
- 実装内容をGitにコミット

## 学んだこと
- MyBatisでは、SQLの実行結果をJavaのオブジェクトに対応付ける必要がある
- `@Results` と `@One` を使用すると、関連する児童情報も取得できる
- `@Setter` がないフィールドには、Springのフォーム送信値が正しく設定されない場合がある
- SQLの `WHERE` に `NULL` が渡されると、更新対象が見つからず、エラーなしで0件更新になることがある
- `@RequestParam` で受け取るパラメータ名は、HTMLの `name` と大文字・小文字まで一致させる必要がある
- `DELETE` では、児童IDと曜日を条件にすることで特定の契約だけを削除できる
- 契約曜日の変更は、既存契約の削除と新規登録でも対応できる

## 苦戦
- `Contract` の `day` に `@Setter` がなく、契約情報を更新してもDBに反映されなかった
- SQL自体はエラーにならず、更新されない原因の特定に時間がかかった
- `dropOffLocation` のSQLカラム名のスペルミスでエラーが発生
- HTMLの `childId` とControllerの `childid` が一致せず、削除時にエラーが発生
- Java・HTML・SQL間でのデータの受け渡しと、命名の一致の重要性を実感した
