# 8/14 学習記録

## 学習内容
- Spring Boot 課題管理アプリの講座を最後まで完走
- Thymeleaf のフラグメントを使って共通レイアウトを作成
- Bootstrap を導入し、画面のレイアウトやフォームの見た目を調整
- フォームのバリデーションエラー表示を Bootstrap に対応

## 学んだこと
- `th:fragment` で共通部分を定義し、各HTMLから共通レイアウトを利用できる
- フラグメントを使うことで、共通部分を一括で修正できる
- Bootstrap は用意されたクラスを指定することで、CSSを細かく書かなくても見た目を整えられる
- `form-label` はラベル、`form-control` は入力欄の見た目を整える
- `mt-3` などのクラスで余白を簡単に設定できる
- バリデーションは、入力された値がルールを満たしているか確認する処理
- `#fields.hasErrors()` で入力エラーの有無を確認できる
- エラー時に `is-invalid` を追加することで、Bootstrap のエラー表示を適用できる

## 苦戦したこと
- Thymeleaf のフラグメントで `title` と `body` がどのように共通レイアウトへ渡されるのか理解するのに苦戦した
- HTMLタグを編集した際に `>` の位置が崩れ、フォームが正しく表示されなくなった
- `th:classappend` や `#fields.hasErrors()` など、バリデーションとBootstrapを組み合わせた記述はまだ自力で再現するのが難しい

## 次回
- 講座全体を復習し、Controller・Service・Repository・Viewの処理の流れを整理する
- コードを見ながら、それぞれが何をしているのか自分の言葉で説明する
- 復習後、完成した課題管理アプリを自分で改造して理解を深める
