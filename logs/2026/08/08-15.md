# 8/15 学習記録

## 学習内容

* Spring Bootで作成した課題管理アプリの復習
* アプリ起動から画面表示までの処理の流れを確認
* `IssueController` から `Service`、`Repository`、DBへ処理が進む流れを復習
* `@RequestMapping` と `@GetMapping` の役割を確認
* DBから取得したデータが `Model` を経由してHTMLに渡される流れを確認

## 学んだこと

* `main()` から直接ブラウザを開いているわけではなく、Spring Bootを起動してブラウザからのリクエストを待っている
* ブラウザから送られたGETリクエストに対応するメソッドが `@GetMapping` によって実行される
* `@RequestMapping("/issues")` をクラスに付けることで、Controller内で共通する `/issues` をまとめて指定できる
* `@RequestMapping` を使わず、それぞれの `@GetMapping` に `/issues` を含めて書くこともできる
* 課題一覧表示では `Controller → Service → Repository → DB` の順番でデータを取得し、`DB → Repository → Service → Controller` と戻ってくる
* Controllerで取得したデータを `Model` に入れ、`return` で使用するHTMLを指定する
* HTMLが複数あってもすべてを参照するわけではなく、その処理で `return` されたHTMLが使用される

## 苦戦したこと

* アプリ起動後、どのタイミングでブラウザからControllerへ処理が移るのかが曖昧だった
* Controller、Service、Repositoryなどを個別には見ていたが、処理全体を一本の流れとして捉えられていなかった
* 今日は集中力があまり続かず、学習時間は30分程度だった
