# 8/5 学習記録

## 学習内容
- Spring Bootの基礎概念を学習
- アノテーションの役割を学習（`@Controller`、`@Override`、`@Transactional`など）
- HTTP、リクエスト、レスポンスの仕組みを理解
- MPAとSPAの違いを学習
- MVCアーキテクチャの概要を学習
- Controller、Service、Repository、View、Entityの役割を学習
- シーケンス図の見方を学習
- DI（Dependency Injection）の導入部分まで学習

## 学んだこと
- アノテーションはSpringやJavaへ役割を伝える目印であることを理解した。
- HTTPはブラウザとサーバーが通信するためのルールであり、リクエストとレスポンスの流れを理解した。
- Springでは役割ごとにクラスを分けることで、変更の影響を最小限にできることを学んだ。
- Controller → Service → Repository → DB → View の処理の流れをイメージできるようになった。
- 本命アプリはMPAで開発する方針に決めた。

## 苦戦したこと
- Spring Bootでは新しい概念が一度に多く登場し、役割や処理の流れを理解することに苦戦した。
- 暗記で覚えようとするのではなく、Controller・Service・Repositoryの役割や処理の流れをイメージ化しながら理解を進めた結果、リクエストからレスポンスまでの一連の流れを説明できるようになった。
