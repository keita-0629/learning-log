# 8/27 学習記録

## 学習内容
- 行きたい場所・行った場所アプリの作成を開始
- Placeエンティティを作成
- Controllerから場所一覧を画面へ渡して表示
- List<Place>を使って複数の場所を管理
- Thymeleafのth:eachを使って一覧表示
- PlaceServiceを作成
- 場所一覧を作る処理をControllerからServiceへ分離
- ControllerからServiceを利用するためのDIを実装

## 学んだこと
- Placeは「場所1件分」のデータを表す
- List<Place>は複数のPlaceをまとめて持つことができる
- add()を使うことでListにPlaceを追加できる
- th:eachはListの中身を1件ずつ取り出して繰り返し表示する
- th:eachを付けたdiv全体が繰り返されるため、名前・都道府県・評価・訪問済みなどを1セットとして表示できる
- Serviceに処理を分けることで、Controllerは画面とのやり取りに集中できる
- Controller → Service → List<Place> → Model → Viewという流れで一覧を表示できる

## 苦戦したこと
- Place、place、placesの違いが途中で混同しやすかった
- th:eachがどの範囲を繰り返しているのか理解するのに少し苦戦した
- Serviceを追加したことで、Controllerとの役割分担やデータの流れが複雑に感じた
- DIを追加してControllerからPlaceServiceを利用する流れで少し混乱した

## 次回
- 新しい機能を追加する前に、現在のコードを上から1行ずつ確認する
- Place → List<Place> → Service → Controller → Model → th:each の流れを一本につなげて復習する
- ControllerとServiceそれぞれの役割を整理してから次の実装へ進む
