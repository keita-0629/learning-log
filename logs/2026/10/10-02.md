# 10/2 学習記録

## 学習内容
- daycare-schedule の現在の実装内容を確認
- Contract と contractDays の役割を復習
- List に複数の Contract を持たせる理由を復習
- Thymeleaf の th:each で List の中身を1件ずつ取り出す流れを復習
- pickupLocation / dropOffLocation など Contract が持つデータの確認
- 曜日ごとの基本送迎設定と、その日だけの変更を分けて考える仕様を確認

## 学んだこと
- new Contract(...) で Contract クラスをもとに契約情報を持ったインスタンスを作る
- contractDays は複数の Contract をまとめて持つ List
- th:each では List から1件ずつデータを取り出し、そのデータに名前を付けて使う
- contractDays は一覧全体、contract はその中から取り出した1件という違いがある
- 曜日ごとの基本送迎設定は、その日の利用希望で送迎先を変更しても書き換えない

## 苦戦
- List 全体の contractDays と、そこから取り出した1件の contract が混ざることがあった
- Contract の各データを HTML 側からどう参照するか、まだ曖昧な部分があった
- コードを部分的には理解できているが、全体のデータの流れを追うところに不安がある

## 次回
- 実コードを上から読み直して、データがどこで作られ、どこへ渡っているかを順番に追う
- Controller → HTML / Thymeleaf → JavaScript の流れを復習する
- 復習後、カレンダーで選択した曜日の基本送迎先を bottom-sheet に表示する処理へ進む
