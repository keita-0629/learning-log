# 10/22 学習記録

## 学習内容
- 職員画面に契約登録フォームを作成
- `form` タグを使用して契約情報の入力欄を実装
- `checkbox` を使用して月曜日〜日曜日の複数選択に対応
- `input type="time"` で開始時間・終了時間の入力欄を実装
- `input type="text"` で迎え先・送り先の入力欄を実装
- `button type="submit"` で登録ボタンを設置
- フォームの送信先を `/staff/contracts`、送信方法をPOSTに設定
- `StaffController` に契約登録用の `@PostMapping` を追加
- `registerContract()` メソッドの作成に着手
- 複数曜日を受け取るための `List<DayOfWeek>` を確認

## 学んだこと
- `radio` は同じ `name` の選択肢から1つだけ選択できる
- `checkbox` は複数の選択肢を同時に選択できる
- `name` はControllerに送信する項目名、`value` は送信する値を指定する
- `DayOfWeek` の曜日は `MONDAY` や `TUESDAY` などの英語で指定する
- `label` で囲むと文字をクリックしてもチェックできる
- `type="time"` で時刻、`type="text"` で文字列を入力できる
- `th:text` は値を表示するための属性であり、フォームの入力項目名には使用しない
- `form` の `action` で送信先、`method` で送信方法を指定する
- `button type="submit"` でフォーム内の入力内容を送信できる
- Spring MVCでは `String` の戻り値で表示画面やリダイレクト先を指定できる
- `@RequestParam` でHTMLから送信された値を受け取れる
- `List<DayOfWeek>` で複数の曜日をまとめて扱える
- HTML → Controller → Service → Controller → リダイレクト → Thymeleafという処理の流れを確認

## 苦戦

- 登録ボタンとフォームの送信先の関係
- POST処理で `String` を戻り値にする理由
- `registerContract()` の引数の型と変数名
- 複数の曜日を受け取るための `List<DayOfWeek>` の使い方
