# 9/9 学習記録

## 学習内容
- 訪問済み・未訪問での絞り込み機能を完成
- GETフォームを使った絞り込み処理
- form / input / hidden の役割を復習
- @RequestParam の役割を復習
- 絞り込み処理全体の流れを復習

## 学んだこと
- form は「どこに・どの方法で送るか」を決める
- input はフォームで送信する値を持つ
- type="hidden" を使うと、画面には表示せず値だけ送信できる
- GETフォームでは input の name と value がURLのパラメータになる
  - visited=true → 訪問済み
  - visited=false → 未訪問
- @RequestParam(required = false) によって、visitedが指定されていない場合も受け取れる
- visitedがnullの場合は全件表示、true/falseの場合は絞り込みを行う
- Repositoryで取得した複数のPlaceはList<Place>として返される
- new Place() は新規追加フォームで使用する空のPlaceオブジェクトを作るために使う

## 苦戦
- @RequestParam(required = false) の意味を忘れていた
- formとinputそれぞれの役割が混ざっていた
- hiddenが値を送るものなのか、inputを隠すためのものなのか混乱した
- new Place() が必要な理由の理解が少し曖昧だった
