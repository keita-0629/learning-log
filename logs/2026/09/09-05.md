# 9/5 学習記録

## 学習内容
- Placeアプリの編集・更新機能を実装
- `edit.html` のフォーム送信先を確認
- Controllerに更新用の`@PostMapping`を追加
- Serviceに`editPlace`メソッドを追加
- Repositoryに`@Update`を使った更新SQLを追加
- `redirect:`と通常のHTML返却の違いを確認

## 学んだこと
- 編集フォームから送られたデータは`Place place`としてControllerで受け取れる
- URLの`{id}`は`@PathVariable`で受け取る
- 更新処理でもController → Service → Repositoryの順にデータを渡していく
- SQLの`UPDATE`は`UPDATE テーブル名 SET 列名 = 値 WHERE 条件`の形で書く
- Repositoryで複数の引数を使う場合、`Place`の中の値は`#{place.name}`のように参照する
- `return "places/edit"`はHTMLをそのまま表示し、`return "redirect:/places"`はブラウザに`/places`へ再アクセスさせる

## 苦戦したこと
- `UPDATE`文を`INSERT`の書き方と混同した
- Javaのテキストブロック`"""`の閉じ方で混乱した
- Repositoryで`id`と`Place`の2つを受け取った場合のSQLからの参照方法に苦戦した
- `redirect:`と通常のHTML返却の違いがまだ少し曖昧
