# 9/24 学習記録

## 学習内容
- カレンダー上で契約曜日に色を付ける処理を実装
- `DayOfWeek` 型を使って曜日情報を扱うように変更
- `Contract` の `day` を `String` から `DayOfWeek` に変更
- `contractDays` から曜日だけを取り出して `contractWeekDays` を作成
- `Model` を使って `contractWeekDays` をHTMLへ渡した
- Thymeleaf の `contains()` を使って、カレンダーの日付が契約曜日か判定
- `th:classappend` と三項演算子を使って、契約曜日に `contract-day` クラスを付与
- CSSで契約曜日の背景色を変更

## 学んだこと
- `DayOfWeek` はJava標準の曜日専用の型
- `List<DayOfWeek>` は `DayOfWeek` 型の値だけを入れるリスト
- `contract.getDay()` は `@Getter` によって作られたGetterで、`Contract` の `day` を取得する
- `date.getDayOfWeek()` は `LocalDate` が持つJava標準のメソッド
- `add()` はListへデータを追加するメソッド
- `contains()` はListの中に指定した値が入っているか確認するメソッド
- `||` は「または」を表し、左右にはそれぞれ条件式が必要
- 三項演算子は `条件 ? trueのとき : falseのとき` の形
- `th:classappend` を使うと、条件に応じてCSSクラスを追加できる
- HTMLに `MONDAY` などを直接書くのではなく、Controllerから渡した契約曜日データを使って判定できる

## 苦戦
- `DayOfWeek` が自作の型かJava標準の型か混乱した
- `contract.getDay()` と `date.getDayOfWeek()` の違いが分かりづらかった
- `th:classappend` をどの `<div>` に書くか迷った
- 三項演算子と `||` の書き方で混乱した
- `contractWeekDays` が何のためのListなのか理解するまで時間がかかった
- 全体の理解度は6割程度なので、処理の流れをもう一度復習したい
