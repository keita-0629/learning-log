# 9/1 学習記録

## 学習内容
- Place.java → List<Place> → PlaceService → PlaceController → Thymeleaf の流れを復習
- `private final PlaceRepository placeRepository` とコンストラクタ注入の役割を復習
- `list.html` に場所追加用フォームを実装
- 場所名・都道府県・評価・訪問済みをフォームから送信できるようにした
- `POST /places` から Controller → Service → Repository → DB へ追加処理が流れることを確認
- 評価入力に `min="1"`、`max="5"` を追加
- 必須項目に `required` を追加
- `visited` の表示を `true / false` から「訪問済み / 未訪問」に変更
- `spring-boot-starter-validation` を追加
- `Place` に `@NotBlank`、`@Min`、`@Max` を追加
- Controller に `@Valid` と `BindingResult` を導入
- バリデーションエラー時に一覧データを再取得して `Model` に渡す処理を追加

## 学んだこと
- `<form action="/places" method="post">` でフォーム内容を `POST /places` に送信できる
- `input` の `name` が `Place` の各フィールドと対応している
- `type="number"` で数値入力、`type="checkbox"` で真偽値を扱える
- `required` はブラウザ側で未入力を防ぐための指定
- `@NotBlank` は文字列が空・空白だけになることを防ぐ
- `@Min`、`@Max` で数値の範囲を指定できる
- `@Valid` を `Place` の前に付けることで、Place.java に書いたバリデーションを実行できる
- `BindingResult` でバリデーション結果を受け取れる
- `bindingResult.hasErrors()` で入力エラーの有無を確認できる
- Controller は `Model` や入力チェックを扱い、Repository はDBとのやり取りに集中させる
- Thymeleafでも `条件 ? 真の場合 : 偽の場合` の形で条件分岐できる
- Mavenの依存関係を追加したあとは、VS Code側でJava classpathの同期が必要になる場合がある
- Maven Wrapper があるプロジェクトでは `.\mvnw.cmd clean compile` でコンパイルできる

## 苦戦したこと
- `private final` とコンストラクタ注入の役割を忘れていて、RepositoryをServiceから使う仕組みの理解に苦戦した
- `BindingResult` や `Model` をRepository側に書いてしまい、ControllerとRepositoryの役割が混ざった
- 同じ `addPlace` メソッドを2つ作ってしまい、どこに処理を追加するか見失った
- Validationの依存関係追加後、VS Code側で同期されず `jakarta.validation` が認識されなかった
- Thymeleafの三項演算子でクォートや半角コロンの記述ミスがあり、500エラーになった
- エラー内容をターミナルから確認し、原因箇所を特定して修正した
