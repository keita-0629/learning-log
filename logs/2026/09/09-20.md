- CSS Grid で曜日・日付を7列表示
- 今月1日の曜日を取得する処理を追加

## 学んだこと
- span は文章の一部分だけを囲って、ThymeleafやCSSの対象にできる
- th:text はタグの中身を置き換える
- LocalDate.now() で今日の日付を取得できる
- getYear() で年、getMonthValue() で月、getDayOfMonth() で日を取得できる
- lengthOfMonth() でその月の日数を取得できる
- List.of() は後から要素を追加する用途には向かない
- ArrayList は add() を使って後から要素を追加できる
- for 文で day を1から月末まで増やし、LocalDate.of() で日付を1日ずつ作れる
- LocalDate.of(年, 月, 日) は指定した日付の LocalDate を新しく作る
- getDayOfWeek() でその日付の曜日を取得できる
- CSS の display: grid でグリッド表示にできる
- grid-template-columns: repeat(7, 1fr) で同じ幅の7列を作れる
- メソッド内で作ったローカル変数は、そのメソッドの実行中だけ使える

## 苦戦

- day++ や <= の書き方を思い出すのに少し苦戦した
- ArrayList の中に for 文が入っているのではなく、
  「空のArrayListを作る → for文で要素をaddする」
  という流れの理解に時間がかかった
- LocalDate.of() と getDayOfWeek() の役割の違いを整理した
