# ToDoアプリ

## 概要

Javaで作成したコンソール版ToDoアプリです。

Javaの基礎学習として制作しました。

---

## 機能

- タスク追加
- タスク一覧表示
- タスク削除
- タスク完了

---

## 使用技術

- Java
- ArrayList
- Scanner
- クラス
- メソッド

---

## 工夫した点

- `Task`クラスを作成し、タスク名と完了状態をまとめて管理
- 処理をメソッドへ分割し、`main()`を見やすくリファクタリング
- タスクが存在しない場合はメッセージを表示するようにした
