# 課題管理アプリ

## 概要

Spring Bootで作成した課題管理Webアプリです。

Spring Bootの基本的な構成や、CRUD処理の流れを学ぶために制作しました。

---

## 機能

- 課題一覧表示
- 課題詳細表示
- 課題新規登録
- 課題編集
- 課題削除
- 入力内容のバリデーション

---

## 使用技術

- Java
- Spring Boot
- Thymeleaf
- MyBatis
- H2 Database
- Bootstrap

---

## 工夫した点

- Controller・Service・Repositoryに役割を分けて処理を実装
- 課題の登録・表示・編集・削除を行うCRUD機能を実装
- 編集時に既存の課題情報を取得し、フォームの初期値として表示
- 登録・編集時にバリデーションを行い、不正な入力を防ぐようにした
- 登録・編集・削除後はリダイレクトし、フォームの再送信を防ぐようにした
- Thymeleafを使用してDBから取得した課題情報を画面に表示
- Bootstrapを使用してフォームやボタンの見た目を整えた
